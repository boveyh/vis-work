# Layout Lab 前端布局知识学习系统设计

日期：2026-09-11

状态：已获用户批准

参考站点：https://cinger007.github.io/vis/

## 1. 项目目标

Layout Lab 是一个可部署到 GitHub Pages 的纯前端双语学习系统，帮助不同基础的用户循序掌握网页布局。它借鉴参考站点清晰的课程首页、章节目录和“讲解 / 代码 / 演示”学习结构，但使用独立的品牌、文案、视觉系统和交互设计。

核心学习闭环：

```text
先看现象 -> 理解原理 -> 阅读关键代码 -> 修改参数 -> 完成挑战
```

成功标准：

- 用户能在首页两次点击内进入任意知识点。
- 理论、代码和演示共享同一知识上下文。
- 用户修改 CSS 属性后，预览立即产生正确变化。
- 网站不依赖账号、数据库或服务端接口。
- 中文与英文链接均可独立分享和刷新。
- 构建产物可直接发布到 GitHub Pages。

## 2. 设计定位

Design Read：面向前端初学者和进阶学习者的交互式知识学习站，以现代技术教材和布局实验室为视觉语言。

设计参数：

- `DESIGN_VARIANCE: 7`：使用非对称首屏和不规则课程地图，同时保持学习路径清晰。
- `MOTION_INTENSITY: 5`：动效用于解释布局变化、内容层级和操作反馈。
- `VISUAL_DENSITY: 6`：信息比宣传页充实，但保留足够留白。

页面采用自主设计的 CSS 变量系统，不套用参考站点的紫色渐变和等分卡片风格。

## 3. 产品范围

第一版包含：

- 首页和课程地图。
- 八个章节的完整结构。
- 盒模型、Flexbox、CSS Grid 三章的完整双语内容。
- 理论知识、关键代码、交互演示三种学习模式。
- 每个完整章节至少一个挑战。
- 浏览器本地学习进度。
- 浅色和深色模式。
- 简体中文和英文切换。
- 桌面、平板和手机布局。
- GitHub Pages 自动部署。

第一版不包含：

- 登录、账号同步和云端存储。
- 评论、排行榜和社交功能。
- 任意 JavaScript 执行环境。
- 后台内容管理系统。

## 4. 课程体系

课程按难度分为四级，共八章：

| 难度 | 章节 | 核心内容 | 章节实战 |
| --- | --- | --- | --- |
| 入门 | 页面如何形成 | HTML 骨架、块级与行内元素、语义结构 | 搭建文章页面 |
| 入门 | 盒模型与文档流 | content、padding、border、margin、尺寸计算 | 修复溢出卡片 |
| 基础 | Flexbox | 主轴、交叉轴、换行、伸缩、对齐 | 导航栏与产品列表 |
| 基础 | 定位与层叠 | relative、absolute、fixed、sticky、z-index | 吸顶导航与弹层 |
| 进阶 | CSS Grid | 网格轨道、区域、自动布局、响应式网格 | 后台控制台骨架 |
| 进阶 | 响应式布局 | 媒体查询、流式尺寸、容器查询、移动端策略 | 三端适配页面 |
| 实战 | 常见页面模式 | Hero、侧边栏、卡片流、圣杯布局 | 博客或作品集首页 |
| 实战 | 综合挑战 | 拆解设计、选择布局方式、完成还原 | 完整响应式页面 |

每章包含 4 至 6 个小节。用户可以按推荐顺序学习，也可以直接跳转到任意章节。

## 5. 单个知识点结构

每个知识点包含以下部分：

### 5.1 理论知识

- 一句话直觉解释。
- 一个布局示意或真实预览。
- 一段正式定义。
- 一个适用场景。
- 一个常见误区。

### 5.2 关键代码

- 只突出影响当前知识点的代码行。
- 支持行号、语法高亮和复制。
- 点击重点行时，右侧预览突出受影响元素。
- 提供“为什么这样写”和“什么时候不适合”。
- 完整 HTML 和 CSS 默认折叠，需要时再展开。

### 5.3 交互演示

- 属性选择器、数值输入和必要的滑块。
- Desktop、Tablet、Mobile 三种预览宽度。
- 实时生成 CSS。
- 复制当前 CSS。
- 重置为初始状态。
- 在同一知识点内切换不同案例。

### 5.4 挑战

挑战给出目标效果和可编辑的起始代码。系统依次提供方向提示、属性提示和完整答案。运行结果通过预定义规则检查，不执行用户输入的任意 JavaScript。

## 6. 信息架构和路由

使用 Hash 路由保证部署在 GitHub Pages 仓库子路径下刷新不产生 404：

```text
/#/zh/                         中文首页
/#/zh/course                  中文课程地图
/#/zh/lesson/box-model        中文盒模型章节
/#/zh/lesson/flexbox          中文 Flexbox 章节
/#/zh/challenge               中文综合挑战
/#/zh/about                   中文项目说明

/#/en/                         英文首页
/#/en/course                  英文课程地图
/#/en/lesson/flexbox          英文 Flexbox 章节
/#/en/challenge               英文综合挑战
/#/en/about                   英文项目说明
```

小节位置使用查询参数保存，例如：

```text
/#/zh/lesson/flexbox?section=main-axis
```

切换语言时只替换 URL 中的语言段，章节、小节、当前标签、演示参数和学习进度保持不变。

## 7. 首页设计

### 7.1 顶部导航

桌面导航高度约 68px，保持单行并在滚动后吸顶。内容为品牌、课程地图、布局挑战、学习说明、语言切换、主题切换和唯一主按钮“继续学习”。手机端使用折叠菜单。

### 7.2 非对称首屏

左侧为价值主张和开始入口，右侧为可真实操作的 Flexbox 演示。

```text
学会布局，不靠背属性。
从盒模型到响应式页面，每个知识点都能运行。
```

用户可以直接修改 `flex-direction` 和 `justify-content`，观察三个元素的排列变化。该演示不是静态截图。

### 7.3 学习路径

用横向递进路径表达“入门 -> 基础 -> 进阶 -> 实战”。悬停或聚焦某个阶段时显示对应章节，手机端转为纵向路径。

### 7.4 章节地图

章节使用大小不同的不规则网格。每个入口只展示章节名称、一句话目标、小节数量和真实学习状态。难度通过面积、排版层级和位置表达，不依赖多种强调色。

### 7.5 布局构建过程

通过四个可切换阶段展示同一页面如何依次加入 Grid、列宽、间距和响应式断点。动画用于解释构建顺序；减少动态效果时改为静态阶段切换。

### 7.6 首页底部

包含最近学习位置、综合挑战入口、项目说明、GitHub 仓库和学习内容说明。

## 8. 章节学习页设计

### 8.1 桌面布局

桌面端使用三栏工作台：

```text
章节目录 | 理论 / 代码 / 演示 | 实时预览与属性控制
```

- 顶部课程栏负责返回课程地图、显示当前章节、切换语言和主题。
- 左侧目录独立滚动，显示当前小节和已完成状态。
- 中间学习区切换理论、关键代码和交互演示。
- 右侧预览始终保持可见，使三个学习标签共享上下文。

### 8.2 移动端布局

小于 768px 时收敛为单栏。底部导航提供“学习、代码、预览、目录”四个入口。目录从底部抽屉打开，预览可切换为全宽面板，代码允许局部横向滚动，但页面本身不横向滚动。

## 9. 中英文切换

### 9.1 入口与行为

- 桌面端使用“中 / EN”分段按钮，位于主题切换旁。
- 移动端语言入口位于导航抽屉顶部。
- 切换语言不刷新整页，不改变当前学习位置和演示状态。
- 首次语言优先级为：用户历史选择、浏览器语言、简体中文。
- 用户选择存入 `localStorage`。

### 9.2 翻译范围

需要本地化：导航、按钮、章节内容、理论、代码注释、演示控件、挑战、提示、错误状态、页面标题和描述。

保持原样：HTML 标签、CSS 属性、JavaScript API、文件名、路径和标准技术缩写。

缺失英文内容时，生产环境回退到中文；开发和构建阶段报告缺失键，避免发布空白内容。

### 9.3 无障碍

- 页面根元素同步设置 `lang="zh-CN"` 或 `lang="en-US"`。
- 语言按钮提供完整的辅助名称。
- 当前语言使用 `aria-pressed="true"`。
- 不使用国旗代表语言。

## 10. 视觉规范

### 10.1 颜色

浅色模式语义色：

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#F4F4F1` |
| 主要面板 | `#FFFFFF` |
| 主要文字 | `#20201E` |
| 次要文字 | `#686862` |
| 分隔线 | `#DADAD4` |
| 强调色 | `#E4572E` |
| 代码背景 | `#1F211F` |
| 成功反馈 | `#287A54` |
| 错误反馈 | `#B64236` |

深色模式保持相同语义关系。整站只使用橙红色作为交互强调色，不在不同章节更换强调色。

### 10.2 字体

- 中文正文优先使用系统中文无衬线字体。
- 英文和数字使用现代无衬线字体。
- 代码使用 Geist Mono、Cascadia Code 或系统等宽字体。
- 首页标题桌面约 64px，移动端约 40px。
- 章节标题桌面约 40px，正文默认 16px。

### 10.3 形状与层级

- 内容面板圆角 14px。
- 按钮和输入控件圆角 8px。
- 标签切换器圆角 10px。
- 层级主要由边框、留白和背景差形成。
- 代码区可使用深色表面，但页面主题保持统一。

### 10.4 图标

统一使用 Phosphor Icons。导航和功能入口不使用 emoji，也不混用多个图标库。

## 11. 动效规范

允许的动效：

- CSS 属性改变时，预览元素平滑进入新位置。
- 标签切换时，内容短暂淡入和轻微位移。
- 章节地图按学习顺序进入视口。
- 完成挑战时，使用边框和短暂颜色变化反馈。

不使用自动轮播、鼠标跟随、发光光标、无目的视差和无限装饰动画。所有动效只改变 `transform` 和 `opacity`，并支持 `prefers-reduced-motion`。

## 12. 技术架构

建议技术栈：

- Vite、React、TypeScript。
- React Router `HashRouter`。
- 原生 CSS Variables 配合 CSS Modules。
- Prism 或 Shiki 提供代码高亮，实施时根据体积和静态构建效果二选一。
- `localStorage` 保存用户偏好和进度。

目录边界：

```text
src/
├─ components/
│  ├─ navigation/
│  ├─ lesson/
│  ├─ playground/
│  └─ challenge/
├─ content/
│  ├─ chapters.ts
│  └─ lessons/
├─ i18n/
│  ├─ zh-CN.ts
│  ├─ en-US.ts
│  └─ index.ts
├─ layouts/
│  ├─ HomeLayout.tsx
│  └─ LessonLayout.tsx
├─ pages/
├─ styles/
├─ utils/
└─ main.tsx
```

主要组件：

- `ChapterMap`：展示章节、难度和学习状态。
- `LessonNavigation`：负责章节与小节导航。
- `LessonTabs`：切换理论、代码和演示。
- `CodeViewer`：代码高亮、行解释和复制。
- `LayoutPreview`：隔离并渲染布局效果。
- `PropertyControls`：根据内容数据生成演示控件。
- `ChallengeRunner`：检查答案并按层级提供提示。
- `ProgressStore`：统一读写本地进度。
- `LocaleProvider`：管理语言、回退和 URL 同步。
- `LanguageSwitch`：提供中英文切换入口。

## 13. 内容数据契约

课程内容与页面组件分离。每个小节包含稳定 ID、双语文本、代码、演示配置和挑战配置。

```ts
interface LocalizedText {
  zh: string;
  en: string;
}

interface LessonSection {
  id: string;
  chapter: string;
  title: LocalizedText;
  summary: LocalizedText;
  theory: {
    intuition: LocalizedText;
    definition: LocalizedText;
    useCase: LocalizedText;
    mistake: LocalizedText;
  };
  code: {
    html: string;
    css: string;
    comments: Record<string, LocalizedText>;
    highlights: number[];
  };
  playground: {
    controls: PlaygroundControl[];
    initialValues: Record<string, string | number | boolean>;
  };
  challenge: {
    prompt: LocalizedText;
    starterCode: string;
    expectedRules: ExpectedRule[];
  };
}
```

预览只接受白名单 CSS 属性和经过约束的值。预览放入隔离容器，防止课程案例的样式影响网站外壳。

## 14. 本地状态

浏览器保存：

- 已完成的小节 ID。
- 上次访问的章节、小节和标签。
- 挑战完成状态。
- 主题和语言偏好。
- 演示区最后一次参数。

进度按稳定内容 ID 保存，与语言无关。切换中英文不会生成两份学习记录。

## 15. 异常和降级状态

- 首次访问：显示推荐起点。
- 有历史记录：显示最近学习位置。
- `localStorage` 不可用：课程仍可使用，但明确提示进度不会保存。
- 内容或路由不存在：提供返回课程地图的操作。
- 演示渲染失败：显示错误解释和重置按钮。
- 用户样式造成溢出：限制在预览容器内，不影响页面外壳。
- 复制失败：自动选中代码并提示手动复制。
- 翻译缺失：生产环境回退中文，构建阶段报告缺失键。
- 小屏空间不足：预览转为独立全宽面板。

## 16. 部署

Vite 的 `base` 使用仓库名，例如：

```ts
base: "/layout-lab/"
```

GitHub Actions 部署流程：

```text
推送 main -> 安装依赖 -> 类型检查 -> 测试 -> 构建 -> 上传 dist -> 发布 Pages
```

静态资源必须通过 Vite 基础路径生成，不能写死站点根路径。

## 17. 测试与验收

### 17.1 功能测试

- 中英文切换保持当前章节、小节、标签和演示参数。
- 主题切换保持当前学习状态。
- 各演示控件生成合法且正确的 CSS。
- 重置、复制、挑战提示和答案检查可用。
- 本地进度在刷新后恢复。

### 17.2 路由与部署测试

- 在 GitHub Pages 仓库子路径下加载首页和资源。
- 直接访问中文和英文 hash 链接。
- 刷新任意章节后仍留在正确页面。
- 分享的语言链接以对应语言打开。

### 17.3 响应式测试

- 在 360px、768px、1024px 和 1440px 宽度验证布局。
- 手机端无整页横向滚动。
- 代码只在自身容器内横向滚动。
- 桌面导航保持单行且不超过 80px 高度。

### 17.4 无障碍测试

- 所有操作可通过键盘完成。
- 标签、语言切换、主题切换和目录抽屉具有正确语义。
- 可见焦点不被删除。
- 浅色和深色模式达到 WCAG AA 对比度。
- 减少动态效果时没有依赖动画才能理解的内容。

### 17.5 质量目标

- Lighthouse 性能、无障碍、最佳实践和 SEO 均以 90 分以上为目标。
- LCP 小于 2.5 秒，CLS 小于 0.1，INP 小于 200 毫秒。
- 构建阶段检查 TypeScript、测试和双语内容完整性。
- 页面不得复制参考站点的品牌、原文或完整视觉表达。

## 18. 实施顺序建议

1. 建立项目、路由、主题、语言和内容数据契约。
2. 完成首页和课程地图的响应式外壳。
3. 完成章节三栏工作台与移动端切换。
4. 完成盒模型章节和通用演示引擎。
5. 完成 Flexbox 与 Grid 内容和挑战。
6. 补齐其余章节结构、空状态和双语文本。
7. 完成功能、响应式、无障碍和 GitHub Pages 部署验证。
