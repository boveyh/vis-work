# Layout Lab 视觉与测验实施计划

规格：`docs/superpowers/specs/2026-09-16-visual-depth-and-assessment-design.md`

## 1. 数据与进度

- 在 `src/data.ts` 增加 `QuizQuestion`、`Quiz` 类型。
- 为八章各配置 4 道章末题，为四阶段各配置 10 道综合题。
- 每题包含中英文题干、三个选项、正确答案、错误提示和知识点。
- 在 `src/App.tsx` 扩展本地进度，分别保存学习证据、章末通过状态、阶段通过状态和未完成作答草稿。
- 保持现有 `layout-lab-section-progress` 与旧 `layout-lab-progress` 迁移逻辑。

## 2. 即时题与完成提示

- 将当前三按钮答案改为可识别的单选题组，加入题号、单选圆点和选中状态。
- 错误反馈只给方向提示，不直接写出正确选项。
- 完成标准第三项改成“已正确解释布局变化”。
- 提交按钮旁显示尚缺预测、演示目标、答案或提交检查中的哪一项。

## 3. 章末小测

- 新建通用 `QuizPanel` 和 `QuizQuestionView`。
- 章节学习证据满足后，在正文末尾开放 4 道章末小测。
- 支持未答数量、错题提示、仅修改错题、全对通过与本地保存。
- 章末通过后，显示下一章；若本章是阶段末章，则显示阶段综合测试入口。

## 4. 阶段综合测试

- 新增 `/:locale/stage/:stageKey/test` 路由与 `StageTestPage`。
- 仅在所属章节章末小测全部通过时开放正式提交；未开放时显示所缺章节。
- 展示约 10 道题、答题进度、错题提示和全对通过状态。
- `/challenge` 保留并继续指向综合布局章节，不改变原有入口职责。

## 5. 三栏学习页与视觉 token

- 将 `LearningLessonPage` 调整为约 220px 导航、流式正文、约 360px 同步教学板。
- 把 `ConceptPlayground` 放入右侧教学板，正文保留任务说明和控制提示，不再重复一套完整演示。
- 右栏桌面端粘性定位，小屏按任务、教学板、原理、即时题顺序进入正文流。
- 在 `src/styles.css` 建立深蓝、米白、橙色和蓝灰的职责 token，并同步深色主题。
- 强化当前章节、当前步骤、答题状态和阶段状态的视觉层级。

## 6. 首页与课程地图状态

- 章节状态区分“学习完成”和“章末通过”。
- 每个阶段增加综合测试入口与通过状态。
- 顶部进度以章末小测通过数为主，保留清晰的继续学习入口。

## 7. 验证

- 运行 `npm run build`，修复 TypeScript 与生产构建错误。
- 在浏览器检查首页、一个普通章节、阶段测试和中英文切换。
- 检查错误答案提示、全部正确通过、刷新后状态恢复和下一步入口。
- 检查 1440px、1024px、768px 与约 360px 布局。
- 检查键盘焦点、禁用状态、正确/错误不只依赖颜色以及减少动态效果。
